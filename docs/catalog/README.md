# Catalog Layer

這個資料夾用來放置 FALO 的 `Model Dish Registry / Catalog Layer` 文件與展示檔。

它的用途是整理模型菜的外部索引、閱讀版本、展示版本與持續補充的母表，不處理 ModelBox 的 schema、relation graph 或系統實作細節。
