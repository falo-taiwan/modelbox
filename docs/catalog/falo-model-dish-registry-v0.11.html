Registry Release v0.11

FALO Model Dish Registry

這是一個可放 GitHub 的公開可讀詳細版，保留原版的結構、命名與教學密度，只收斂不必要的私有資訊。兩種版本都應詳細保留模型菜分類與細節，差別只在公開版的精度控管。這一版同時新增 PM11 與完整 IM 系列，讓 FALO 的顧問、教材與場景系統盤面更完整。

版本定位

這不是重寫版

v0.11 高度參考原版內容與結構，保留 FALO Registry 的原始敘事與教學密度。

這是公開可讀的詳細版

主要收斂的是本機絕對路徑、私有執行痕跡與不必要的環境識別資訊，同時保留完整的分類與敘事密度。

不是薄摘要

公開版與個人版都要詳細放進模型菜分類與細節；公開版只降低精度，不降低內容厚度。

新增主軸

這次把 AI 交付橋接能力收成 PM11，並將 local-first-im 正式升級成完整 IM 系列。

公開版的原則不是把模型菜寫薄，而是維持完整分類、能力拆解、關聯與用途，再把敏感精度降一階。

v0.11 升版重點

新增 PM11

把 MCP / SSH / GitHub push 橋接能力整理成 FALO 可提供的顧問服務、教材模組與元件型模型菜。

新增 IM 系列

將 local-first-im 納入為一條完整系統線，並更明確收斂成 Local-first IM Workbench 的主系統定位。

補概念條目

新增 CC25 與 CC26，分別承接 AI 交付橋接與 Local-first 協作邊界。

公開版邊界

保留原版內容密度與版本脈絡，但將公開版改寫成 GitHub 可直接展示的公開可讀詳細版。

詳細度原則

不管公開版或個人版，都應把各模型菜分類與細節放進去；公開版只是不放得太精確。

PM11｜AI Delivery Bridge

一句話定位

讓 FALO 能透過 MCP、SSH 與 GitHub push，把對話式 AI 任務橋接到真實工作環境與交付流程。

適用環境

ChatGPT Codex、Claude Cowork，以及後續可擴充的對話式 AI 執行環境。

服務定位

這條模型菜可以同時對應顧問服務、教材模組與可組件化的橋接能力。

重要邊界

重點不是工具綁定，而是 AI 如何從對話走到交付。

FALO 在這裡扮演的是「橋接層」：幫使用者把任務、規則、工具存取與交付動作連起來，而不是只停在對話或提示詞。

IM01｜Local-first IM Workbench

主系統定位

把即時通訊、AI Client、Prompt 管理與資料閉環整合在地端工作台中，作為 Falo Communication OS 的 MVP 原型。

教學價值

初學者可以透過這條線看懂 Browser Client、Local Server、Identity、Message Routing 與本地紀錄的關係。

顧問價值

這不是單一聊天室功能，而是一個可拆元件、可治理、可延後上雲的場景型系統。

核心邊界

Local-first IM: 地端即時，雲端延遲保存。

Dev 版

static/index.html 是 Local-first IM Dev 實作介面版，偏操作、測試、稽核與多人 / 多 client 驗證。

Overview 版

docs/external-overview.html 是外部說明版，偏非工程讀者、教學展示與系統定位說明。

關聯主題

Communication OS、Prompt Manager、Local Data Hub、GAS Sync、AI Logging Shell、HITL。
